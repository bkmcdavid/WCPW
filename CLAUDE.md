# CLAUDE.md — West Coast Plato Workshop website

## What this repo is
The website for the West Coast Plato Workshop (WCPW), served via GitHub Pages
at westcoastplatoworkshop.com (custom domain via the CNAME file). Static
HTML/CSS — no build step, no framework. Edit the .html files and stylesheet directly.

## Voice & tone
Warm, collegial, lightly playful — a scholarly community that takes Plato
seriously but not itself too seriously. Short, clear sentences. Avoid
promotional or corporate phrasing.

## The "Upcoming Meeting" page lifecycle
1. Before a meeting: full logistics (schedule, keynote, travel, lodging, local tips).
2. After it concludes: replace those with (a) a group photo of that year's
   participants and (b) a brief announcement of next year's meeting (host,
   organizers, and a note that dialogue focus and deadlines will follow).
Preserve existing layout/classes; match the design already in the stylesheet.

## Design
Match existing fonts, colors, navigation, and the Plato cartoon branding.
Reuse existing CSS classes rather than adding new ones.

## Images
Participant/content photos go in images/. Reference web-optimized versions
(~1800px wide), not full-resolution camera originals.
